# API Для получения графа лекарственных средств
## Назначение
Получение структуры графа для послдующего отображения
## URL
```GET api/v1/graph/?id=[id лекарственных средств]```
## Аутентификация
Не требуется
## Вход
|**параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:----------:|:-------------|:-----------------|:-----------|
|id          |Array(integer)|Да                |Массив id ЛС|

### Пример входных данных
```GET api/v1/graph/?id=[6, 20]```
```GET api/v1/graph/?id=[6]```

## Выход
|**параметр**|**Тип данных**|**Обязательность**|**Описание**        |
|:----------:|:-------------|:-----------------|:-------------------|
|nodes       |Array[Object] |Да                |Массив узлов графа  |
|links       |Array[Object] |Да                |Массив связей       |
|name        |Array[String] |Да                |Список названия ЛС  |
|maxLevel    |Integer       |Да                |№ Максимального узла|

#### Объект nodes
|**параметр**|**Тип данных**|**Обязательность**|**Описание**        |
|:----------:|:-------------|:-----------------|:-------------------|
|name        |String        |Да                |Название узла       |
|label       |Strting       |Да                |Тег для узла        |
|id          |String        |Да                |Id узла             |
|level       |Integer       |Да                |Уровень узла в графе|
|parents     |Array(String) |Да                |Массив родителей    |
|weight      |Integer       |Да                |Вес                 |


Допустимые значения `label`<br/>
`absorbtion` - Всасывание, <br/>
`action` - Действие, <br/>
`excretion` - Выведение, <br/>
`group` - Группа, <br/>
`prot_link` - Связь с белками, <br/>
`mechanism` - Механизм, <br/>
`metabol` - Метаболизм, <br/>
`hormone` - Гормон, <br/>
`side_e` - Побочный эффект, <br/>
`prepare` - Припарат, <br/>
`distribution` - Распределение, <br/>

#### Объект links
|**параметр**|**Тип данных**|**Обязательность**|**Описание**        |
|:----------:|:-------------|:-----------------|:-------------------|
|source      |String        |Да                |Id родителя узла    |
|target      |Strting       |Да                |Id потомка узла     |

### Статусы ответа
200 - Граф для лекарственных средств получен<br/>
400 - Граф для выбранных лекарственных средств не существует<br/>
404 - Ресурс не найден<br/>
500 - Ошибка определения совместимости<br/>
