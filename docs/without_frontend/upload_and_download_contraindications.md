# API Загрузки и выгрузки противопоказаний
## Импорт противопоказаний
Импорт противопоказаний
## URL
```POST api/v1/contraindications/load_and_link/```

## Аутентификация
Требуемый статус: `нет`

## Вход
|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|file|.json|да|файл с графом|

### Пример запроса
Метод: POST

URL: http://127.0.0.1:8000/api/v1/contraindications/load_and_link/

Тип: form-data
    file → some_name.json


### Статусы ответа
200 — Противопоказания загружены успешно<br/>
400 — Файл с ЛС и противопоказания не загружен<br/>
500 — При загрузке противопоказаний в БД произошла ошибка<br/>

### Пример успешного ответа
```json
{
  "result": {
    "status": 200,
    "message": "Противопоказания загружены успешно"
  },
  "data": {}
}
```
### Пример ответа при некорректном файле
```json
{
  "result": {
    "status": 400,
    "message": "Файл с ЛС и противопоказания не загружен"
  },
  "data": {}
}
```
