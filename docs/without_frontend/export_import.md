# API Загрузки и выгрузки граф и весов для графа
## Импорт графа и весов для графа
Импорт графа и весов для графа
## URL
```POST api/v1/graph/storage_graph/```

## Аутентификация
Требуемый статус: `admin`

## Вход
|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|graph_file|.json|да|файл с графом|
|probability_file|.json|да|файл с весами для графа|

### Пример запроса
Метод: POST

URL: http://127.0.0.1:8000/api/v1/graph/storage_graph/

Тип: form-data
    graph_file → graph.json
    probability_file → weights.json


### Статусы ответа
200 — Граф и вероятности успешно загружены<br/>
400 — Не был отправлен файл с графом или весами<br/>
500 — Ошибка при загрузке графа или весов<br/>

### Пример успешного ответа
```json
{
  "result": {
    "status": 200,
    "message": "Граф и вероятности успешно загружены"
  },
  "data": {}
}
```
### Пример ответа при некорректном файле
```json
{
  "result": {
    "status": 400,
    "message": "Не был отправлен файл с графом."
  },
  "data": {}
}
```

## Импорт графа и весов для графа
Импорт графа и весов для графа
## URL
```GET api/v1/graph/storage_graph/```

## Аутентификация
Требуемый статус: `аноним`

### Пример запроса
Метод: GET

URL: http://127.0.0.1:8000/api/v1/graph/storage_graph/


### Статусы ответа
200 — ZIP-архив с двумя JSON-файлами<br/>
404 — Файл с графов  или весами - пустой<br/>
500 — Ошибка при выгрузки графа или весов<br/>

### Пример успешного ответа

graph_export_число_ЛС.zip

#### Замечание
Если использовать Postman, файл изначально представлен в бинарном виде и его нужно сохранить как zip.

### Пример ответа при некорректном файле
```json
{
  "result": {
    "status": 400,
    "message": "Не был отправлен файл с графом."
  },
  "data": {}
}
```
