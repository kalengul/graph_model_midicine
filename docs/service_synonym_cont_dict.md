
# API Работы со словарём синонимов

## Получение текущего словаря
Возвращает загруженный словарь синонимов

### URL
```GET api/v1/dictionary/```

### Аутентификация
Требуемый статус: `admin`

### Статусы ответа
200 - Словарь успешно получен
500 - Ошибка при получении словаря

### Пример успешного ответа
```json
{
    "result": {
        "status": 200,
        "message": "Словарь успешно получен"
    },
    "data": {
        "current_file": "dict_synonym_contraindications.json",
        "total_keys": 190,
        "total_strings": 438,
        "is_loaded": true,
        "dictionary": {
            "аневризма сосудов": [
                "аневризма сосудов",
                "аневризмы сосудов"
            ],
            "кровотечение": [
                "активное кровотечение",
                "активные кровотечения",
                "кровотечение",
                "активное клинически значимое кровотечение"
            ],
        }
    }
}
```

## Загрузка словаря из файла
Загружает словарь синонимов из указанного файла

### URL
```POST api/v1/dictionary/```

### Аутентификация
Требуемый статус: `admin`

### Вход
| **Параметр** | **Тип данных** | **Обязательность**  | **Описание**  |
|--------------|----------------|---------------------|---------------|
| file         | String         |   да                | `.json` файл  |
| save	       | String	        |   нет	              | Имя файла для сохранения |

```json
{
  "file": "new_dictionary.json"
}
```

### Статусы ответа
200 - Словарь успешно загружен
400 - Не указан путь к файлу или ошибка загрузки
500 — Внутренняя ошибка

### Пример успешного ответа
```json
{
  "result": {
    "status": 200,
    "message": "Словарь успешно загружен"
  },
  "data": {
    "path": "new_dictionary.json",
    "total_keys": 30,
    "dictionary": {
      "аллергия": ["аллергическая реакция"]
    }
  }
}
```

# API Работы с рабочей директорией словарей синонимов

## Получение списка доступных словарей из рабочей директории
Возвращает список всех JSON-файлов в директории словарей

### URL
```GET api/v1/dictionary/directory/```

### Аутентификация
Требуемый статус: `admin`

### Статусы ответа
200 - Список словарей получен
500 - Внутренняя ошибка


```json
{
    "result": {
        "status": 200,
        "message": "Список словарей получен"
    },
    "data": {
        "total_files": 2,
        "dictionaries": [
            {
                "name": "dict_synonym_contraindications.json",
                "size_kb": 58.64,
                "modified": "2026-02-18 20:18:00",
                "is_current": true
            },
            {
                "name": "dict_synonym_contraindications_manual.json",
                "size_kb": 58.65,
                "modified": "2026-02-17 19:21:45",
                "is_current": false
            }
        ],
        "current_loaded": "dict_synonym_contraindications.json"
    }
}
```



## Выбор словаря из рабочей директории по имени
Загружает словарь из директории по имени файла

### URL
```POST api/v1/dictionary/directory/```

### Аутентификация
Требуемый статус: `admin`

### Вход

| **Параметр** | **Тип данных** | **Обязательность**  | **Описание**  |
|--------------|----------------|---------------------|---------------|
| name         | String         |   да                | Имя файла словаря в директории  |


### Пример запроса
```json
{
  "name": "dict_synonym_contraindications.json"
}
```

### Статусы ответа
200 - Словарь загружен
400 - Не указано имя файла
404 - Файл не найден
500 - Внутренняя ошибка


### Пример успешного ответа
```json
{
    "result": {
        "status": 200,
        "message": "Словарь dict_synonym_contraindications_manual.json загружен"
    },
    "data": {
        "name": "dict_synonym_contraindications_manual.json",
        "total_keys": 190
    }
}
```
