# API Для обмена данными для сети Байеса
## Назначение
Определение совместимости ЛС по сети Байеса
## URL
```POST api/v1/polifarmakoterapiya-bayes/```
## Аутентификация
Не требуется
## Вход
|**параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-------:|:--------|:--------|:------|
|drugs    |Array(integer)|да|массив id ЛС|
|humanData|Object|нет|Данные для персонализации|

#### Объект humanData
|**параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:----------:|:--------|:--------|:------|
|age         |String   |нет      |Принимает одно из вариантов сзначений "child" "average" "pension"|
|gender      |String   |нет      |Принимает одно из вариантов сзначений "man" "woman"|
|cont_list   |Array(integer) |нет      |Список id противопоказаний|

### Пример входных данных
```json
{
    "drugs": [1, 2], 
    "humanData":{
        "age": "child",
        "gender": "woman",
        "cont_list": [1, 2]
    }   
}
```
## Выход
|**параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|сompatibility_bayes|String|нет|Код результата оценки совместимости по сети Байеса|
|rank_iteractions|Integer|нет|Ранг совместимости по сети Байеса (если нет, то присылать undefined)|
|side_effects|Array[Object]|да|Список побочек с рангами|
|combinations|Array[Object]|нет|Применимость комбинации с другими лекарственными средствами (если нет, то присылать undefined)|
|drugs|Array(String)|да|Список названий проверяемых ЛС|

#### Объект side_effects
|**параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|сompatibility|String|да|Код результата оценки совместимости по сети Байеса|
|effects|Array(Object)|да|Список побочек с рангами с данным кодом совместимости|

#### Объект effects
|**параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|se_name|String|да|Название побочного эффекта|
|rank|Integer|да|Ранг появления|

#### Объект combinations
|**параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|сompatibility|String|да|Код результата оценки совместимости по сети Байеса|
|drugs|Array(String)|да|Список названий ЛС с данным кодом совместимости|

Допустимые значения `сompatibility_bayes`, `сompatibility`<br/>
`compatible` - Совместимы, <br/>
`incompatible` - Несовместимы,  <br/>
`caution` - С осторожностью, <br/>
`unknown` - Неизвестно, <br/>
`banned` - Запрещено <br/>

### Статусы ответа
200 - Совместимость ЛС по сети Байеса успешно расcчитана<br/>
204 - Нет сведений о совместимости<br/>
400 - Лекарственное средство – [название лс] не найдено<br/>
404 - Ресурс не найден<br/>
500 - Ошибка определения совместимости<br/>

### Пример выходных данных при успешном ответе
```json
{
    "result": {
        "status": 200, 
        "message": "Совместимость ЛС по сети Байеса успешно расcчитана"
    },
    "data":{
        "сompatibility_bayes": "unknown", 
        "rank_iteractions": "undefined",
        "side_effects": [
            {
                "сompatibility":"undefined",
                "effects": [{
                    "se_name": "брадикардия",
                    "rank": 0.1,
                }]

            }],
        "combinations":"undefined",
        "drugs": ["амиодарон", "амлодипин"]
    },    
}
```

# API Для получения списка противопоказаний
## Назначение
Получение списка возможных противопоказаний для пациента
## URL
```GET api/v1/contraindications/?id={id противопоказания}```
## Аутентификация
Не требуется

### Вход
Не принимает параметров

### Выход
|**Параметр** |**Тип данных** | **Описание**               |
|-------------|---------------|----------------------------|
| cont_id     | Integer       | ID противопоказания        |
| cont_name   | String        | Название противопоказания  |
| cont_weigth | Integer       | Вес противопоказания       |

### Статусы ответа
200 — Успешное получение данных<br/>
401 — Неавторизованный доступ<br/>
404 — Отсутствие искомых данных<br/>
500 — Ошибка работы сервера<br/>
### Пример успешного ответа
```json
{
    "status": 200,
    "message": "Группа противопоказаний получена",
    "data": [
        {"cont_id": 1, "cont_name": "противопоказание 1", "cont_weigth": 0.50},
        {"cont_id": 2, "cont_name": "противопоказание 2", "cont_weigth": 0.22}
    ]
}
```

# API Для добавления противопоказания
## Назначение
Добавление противопоказаний для пациента
## URL
```POST api/v1/contraindications/```
## Аутентификация
Требуемый статус: `admin`

### Вход
|**параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-------:|:--------|:--------|:------|
|cont_name    |String|да|название противопоказания|
|cont_weigth|Number|нет|Ранг (вес) противопоказания|

### Выход
|**Параметр** |**Тип данных** | **Описание**               |
|-------------|---------------|----------------------------|
| cont_id     | Integer       | ID противопоказания        |
| cont_name   | String        | Название противопоказания  |
| cont_weigth | Integer       | Вес противопоказания       |

### Статусы ответа
200 — Успешное добавление данных<br/>
400 — Некорректные данные (в частности, если такая запись уже есть в БД)<br/>
401 — Неавторизованный доступ<br/>
500 — Ошибка работы сервера<br/>
### Пример запроса
```json
{
    "cont_name": "противопоказание 1",
    "cont_weigth": 0.1
}
```
### Пример запроса без указания веса
```json
{
    "cont_name": "противопоказание 2"
}
```


### Пример успешного ответа
```json
{
    "status": 200,
    "message": "Противопоказание успешно добавлено",
    "data": {"cont_id": 1, "cont_name": "противопоказание 1", "cont_weigth": 0.50},
}
```
### Пример успешного ответа без указания веса
```json
{
    "status": 200,
    "message": "Противопоказание успешно добавлено",
    "data": {"cont_id": 2, "cont_name": "противопоказание 2", "cont_weigth": 0.00},
}
```
