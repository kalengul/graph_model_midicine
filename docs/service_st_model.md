# API Управления моделью эмбеддингов

## Получение информации о модели
Возвращает информацию о текущей загруженной модели эмбеддингов

### URL
```GET api/v1/st_model/```

### Аутентификация
Требуемый статус: `admin`

### Статусы ответа
200 - Информация о модели успешно получена
500 - Внутренняя ошибка сервера

### Пример успешного ответа
```json
{
  "result": {
    "status": 200,
    "message": "Информация о модели успешно получена"
  },
  "data": {
    "is_loaded": true,
    "config": {
        "model_name": "all-MiniLM-L6-v2",
        "threshold": 0.75,
        "cache_size": 1000
    }
    
  }
}
```


## Обновление конфигурации модели
Обновляет параметры модели и перезагружает её

### URL
```POST api/v1/st_model/```

### Аутентификация
Требуемый статус: `admin`

### Вход
Передаются поля для обновления модели

| **Параметр** | **Тип данных** | **Обязательность**  | **Описание**  |
|--------------|----------------|---------------------|---------------|
| model_name   | String         |   нет               | Имя модели, по умолчанию  "all-MiniLM-L6-v2"  |
| threshold	   | Float	        |   нет	              | Порог схожести (0-1), по умолчанию 0.85 |
| cache_size   | Integer	    |   нет	              | Размер кэша эмбеддингов, по умолчанию 1000 |

### Пример запроса
```json
{
  "model_name": "model_name",
  "threshold": 0.85,
  "cache_size": 1000
}
```

### Статусы ответа
200 - Модель успешно обновлена и загружена
400 - Ошибка валидации данных
500 - Не удалось загрузить модель или внутренняя ошибка

```json
{
    "result": {
        "status": 200,
        "message": "Модель успешно обновлена и загружена"
    },
    "data": {
        "is_loaded": true,
        "config": {
            "model_name": "rubert-tiny2",
            "threshold": 0.94,
            "cache_size": 500
        }
    }
}
```
