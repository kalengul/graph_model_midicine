# API для извлечения данных пациента из медкарты

## Назначение
Анализ медицинских `.docx` документов для извлечения структурированных данных пациента (возраст, пол) и списка противопоказаний.

## URL
```POST api/v1/humandata_from_medcard/```


## Аутентификация
Не требуется (Публичный эндпоинт)

## Вход
На входе в теле запроса передаётся файл медицинской карты.

| **Параметр** | **Тип данных** | **Обязательность**  | **Описание** |
|--------------|----------------|---------------------|---------------|
| file         | file (`.docx`) | да                  | Файл медицинской карты в формате `.docx` (макс. 10 МБ) |

### HTTP-заголовки
Content-Type: multipart/form-data


### Пример входных данных
```json
{
    "medCard": binary,   
}
```


### Статусы ответа

| **Код**                       |                        **Описание**               | 
|:------------------------------|:--------------------------------------------------|
|   200                         |   Файл успешно обработан, данные извлечены        | 
|   400                         |   Файл не прикреплён или неверный формат (.docx)  | 
|   413                         |   Файл слишком большой (> 10 МБ)                  | 
|   500                         |   Внутренняя ошибка сервера при обработке файла   | 


### Вывод при успешной обработке
```json
{
    "result": {
        "status": 200,
        "message": "Данные для автозаполнения получены"
    },
    "data": {
        "age": "child",
        "gender": "woman",
        "cont_list": [1, 2]
    }
}
```

### Вывод при отсутствии файла
```json
{
    "result": {
        "status": 400,
        "message": "Файл не прикреплён. Используйте поле 'file'."
    },
    "data": {}
}
```

### Вывод при неверном формате файла
```json
{
    "result": {
        "status": 400,
        "message": "Поддерживаются только файлы .docx"
    },
    "data": {}
}
```

### Вывод при превышении размера файла
```json
{
    "result": {
        "status": 413,
        "message": "Файл слишком большой (> 10 МБ)"
    },
    "data": {}
}
```

### Вывод при внутренней ошибке сервера
```json
{
    "result": {
        "status": 500,
        "message": "Ошибка обработки: <текст ошибки>"
    },
    "data": {}
}
```
