# API Для получения меню
## Назначение
Добавление группы ЛС
## URL
```GET api/v1/getMenu/```
## Аутентификация
Не требуется

## Вход
### Пример входных данных
Для добавления группы ЛС ```GET api/v1/getMenu/``` <br/>
 
## Выход
На выход отправляет статус выполнения запроса и меню для отображения на странице<br/>
#### Элемент меню
|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|title|String|да|Заголовок мею для пользователя|
|slug|String|да|Ссылка на страницу пользователя|

### Компоненты меню
|**title**|**slug**|
|:-----:|:--------|
|Взаимодействие по MedScape|`/computationMedScape`|
|Взаимодействие по Fortran|`/computationFortran`|
|Добавить данные|`/addData`|

### Статусы ответа
200 - Меню получено<br/>
400 - Ошибка при получении меню<br/>
500 - Неизвестная ошибка сервера <br/>

```json
    },

}
```
