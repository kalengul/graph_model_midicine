# API Для поиска лекарственных средств
## Назначение
Поиск лекарственных средств по МНН и торговым названиям с группировкой результатов
## URL
GET `api/v1/search-drugs/`

## Аутентификация
Не требуется

## Вход
На вход принимает поисковый запрос и ограничение по количеству результатов

|Параметр|Тип данных|Обязательность|Описание|
|:-----:|:--------|:--------|:------|
|q|string|да|Поисковый запрос|
|limit|integer|нет|Количество результатов (по умолчанию 10)|

### Пример входных данных
GET `api/v1/search-drugs/?q=бри&limit=10`

## Выход
На выход выдает список лекарственных средств, подходящих под поисковый запрос.
Поиск происходит по МНН (drug_name) и торговым названиям (trade_names) с начала слова.

|Параметр|Тип данных|Обязательность|Описание|
|:-----:|:--------|:--------|:------|
|query|string|да|Поисковый запрос|
|count|integer|да|Количество найденных результатов|
|results|array(object)|да|Список найденных лекарственных средств|

Каждый объект в массиве results содержит:

|Параметр|Тип данных|Обязательность|Описание|
|:-----:|:-------|:--------|:------|
|id|integer|да|ID лекарственного средства|
|drug_name|string|да|Название МНН|
|dg_id|array(integer)|да|Список ID групп ЛС|
|nosology_id|integer|да|ID нозологии|
|trade_names|array(object)|да|Список торговых названий, подходящих под запрос|

Каждый объект в массиве trade_names содержит:

|Параметр|Тип данных|Обязательность|Описание|
|:-----:|:-------|:--------|:------|
|id|integer|да|ID торгового названия|
|name|string|да|Торговое название|

### Статусы ответа
200 - Результаты поиска получены
400 - Параметр "q" обязателен
500 - Неизвестная ошибка сервера
