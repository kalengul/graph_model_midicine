# API Для получения побочных эффектов
## Назначение
Получение одного или группы побочных эффектов
## URL
```GET api/v1/getSideEffect/?id={id}```
## Аутентификация
Не требуется

## Вход
На вход получает id получаемого побочного эффекта. Если id не указан, то выводится список всех побочных эффектов<br/>

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|se_id|integer|нет|id побочного эффекта|

### Пример входных данных
Для получение одного побочного эффекта ```GET api/v1/getSideEffect/?se_id=1``` <br/>
Для получение списка побочного эффекта ```GET api/v1/getSideEffect/```

## Выход
На выход выдает список побочных эффектов или информацию о конкретном побочном эффекте<br/>

Выходные данные для одного побочного эффекта<br/>

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:-------|:--------|:------|
|id|string|да|id побочного эффекта|
|se_name|string|да|Название побочного эффекта|

Выходные данные для списка побочного эффекта<br/>

|**Праметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----|:--------|:--------|:------|
|side_effects|Aray(object)|да|Список объектов побочных эффектов|

### Статусы ответа
200 - Побочный эффект найден / список побочных эффектов получен <br/>
400 - Побочный эффект [название] не найден <br/>
500 - Неизвестная ошибка сервера <br/>

### Пример выходных данных для группы ЛС
```json
{
    "result": {
        "status": 200, 
        "message": "Список ЛС получен"
    },
    "data": [
        {
            "id": "1",
            "se_name": "брадикардия"
        },
        {
            "id": "2",
            "se_name": "почечная недосточность"
        },
    ]
}
```

### Пример выходных данных для одного ЛС
```json
{
    "result": {
        "status": 200, 
        "message": "ЛС получено"
    },
    "data": {
        "id": "1",
        "se_name": "брадикардия"
    }
}
```

### Пример выходных данных при ошибке
```json
{
    "result": {
        "status": 400, 
        "message": "Ошибка при получении спобочного эффекта брадикардия"
    },
    "data": {}
}
```


# API для добавления новой побочки
## Назначение
Добавление нового побочного эффекта
## URL
```POST api/v1/addSideEffect```
## Аутентификация
Требуемый статус: `admin`

## Вход
На вход в теле запроса получает название побочки и опционально список коэффициэнтов риска ее появления у имеющихся ЛС<br/>

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|se_name|String|да|название побочного эффекта|
|drugs|Array(Objact)|нет|Список ЛС|

#### Объект side_effects
|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|drug_id|String|да|id ЛС|
|rank|Integer|да|ранг появления побочки|

### Пример входных данных
Для добавления побочного эффекта ```POST api/v1/addSideEffect/``` <br/>
Тело запроса: <br/>
```json
{
    "se_name": "почечная недостаточность",
    "side_effects": [
        {
            "drug_id": 1,
            "rank": 0.8
        }
    ]
}
```
 
## Выход
На выход отправляет статус выполнения запроса и соответсвующее сообщение<br/>

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|id|String|да|id побочного эффекта|
|se_name|String|да|Название побочного эффекта|

### Статусы ответа
200 - Побочный эффект [название] добавлен<br/>
400 - Побочный эффект [название] уже существует<br/>
500 - Неизвестная ошибка сервера <br/>

### Пример выходных данных при успешном добавлении ЛС
```json
{
    "result": {
        "status": 200, 
        "message": "Побочный эффект почечная недостаточность добавлен"
    },
    "data": {
        "se_name": "почечная недостаточность",
        "id": 1
    }
}
```

### Пример выходных данных при ошибке
```json
{
    "result": {
        "status": 400, 
        "message": "Побочный эффект почечная недостаточность уже существует"
    },
    "data": {}
}
```

# API для обновления рангов побочных эффектов
## Назначение
Добавление нового побочного эффекта
## URL
```PUT api/v1/updateRanks```
## Аутентификация
Требуемый статус: `admin`

## Вход
На вход в теле запроса получает id побочки, id ЛС и новое значение ранга<br/>

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|update_rsgs|Array(Objact)|да|Массив рангов для обновления|

#### Объект update_rsgs
|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|drug_id|String|да|id ЛС|
|se_id|String|да|id побочного эффекта|
|rank|Integer|да|новый ранг появления побочки|

### Пример входных данных
```PUT api/v1/updateRanks/``` <br/>
Тело запроса: <br/>
```json
{
    "update_rsgs": [
        {
            "drug_id": 1,
            "se_id": 1,
            "rank": 0.8
        }
    ]
}
```
 
## Выход
На выход отправляет статус выполнения запроса и соответсвующее сообщение<br/>

### Статусы ответа
200 - Ранги обновлены<br/>
400 - Побочный эффект не существует / ЛС не существует / Ранг задан некорректно<br/>
500 - Неизвестная ошибка сервера <br/>

### Пример выходных данных при успешном добавлении ЛС
```json
{
    "result": {
        "status": 200, 
        "message": "Ранги обновлены"
    },
    "data": {}
}
```

### Пример выходных данных при ошибке
```json
{
    "result": {
        "status": 400, 
        "message": "Ранг ззадан некорректо"
    },
    "data": {}
}
```

# API для получения рангов побочных эффектов

## URL

## Аутентификация

## Вход
На вход запрос не передает никаких дополнительных параметров<br/>

### Пример входных данных
```GET api/v1/getRanks/``` <br/>
 
## Выход
На выход отправляет статус выполнения запроса, соответсвующее сообщение и список побочек с рангами для ЛС<br/>

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|

|se_ranks|Array(Objact)|да|Массив рангов побочных эффектов|

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|

|se_id|string|да|id побочки|
|drug_id|string|да|id ЛС|
|rank|integer|да|значение ранга|

200 - Ранги получены<br/>
400 - Ошибка при получении ранга<br/>
500 - Неизвестная ошибка сервера <br/>

```json
{
```

```json
    "data": {}
```

# API для удаления побочных эффектов
## Назначение
Удаление побочных эффектов
## URL
```DELETE api/v1/deleteSideEffect/?se_id=[id]```
## Аутентификация
Требуемый статус: `admin`
## Вход
На вход в теле запроса получает id побочки параметр не отправляется, то выдается ошибка 400<br/>

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|se_id|String|нет|id побочного эффекта|

### Пример входных данных
```DELETE api/v1/deleteSideEffect/?se_id=1``` <br/>
 
## Выход
На выход отправляет статус выполнения запроса и соответсвующее сообщение<br/>

### Статусы ответа
200 - [название] удалено<br/>
400 - Ошибка определения удаляемого объекта<br/>
500 - Неизвестная ошибка сервера <br/>

### Пример выходных данных при успешном добавлении ЛС
```json
{
    "result": {
        "status": 200,
```

### Пример выходных данных при ошибке
