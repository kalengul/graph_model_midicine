# API Для получения группы ЛС
## Назначение
Получение списка групп ЛС или информации об одной группе ЛС
## URL
```GET api/v1/getDrugGroup/?id={id}```
## Аутентификация
Не требуется

## Вход
На вход получает id получаемой группы ЛС. Если id не указан, то выводится список всех групп ЛС<br/>

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|dg_id|integer|нет|id группы ЛС|

### Пример входных данных
Для получение одной группы ЛС ```GET api/v1/getDrugGoup/?dg_id=1``` <br/>
Для получение списка групп ЛС ```GET api/v1/getDrugGoup/```

## Выход
На выход выдает список групп ЛС или информацию об одной группе ЛС<br/>

Выходные данные для одного ЛС<br/>

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:-------|:--------|:------|
|id|string|да|id группы ЛС|
|dg_name|string|да|Название группы ЛС|

Выходные данные для списка ЛС<br/>

|**Праметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----|:--------|:--------|:------|
|drugGroups|Aray(object)|да|Список объектов групп ЛС|

### Статусы ответа
200 - Группа ЛС получена / Список групп ЛС получен <br/>
400 - Группа ЛС не найдена <br/>
500 - Неизвестная ошибка сервера <br/>

### Пример выходных данных для группы ЛС
```json
{
    "result": {
        "status": 200, 
        "message": " групп ЛС получен"
    },
    "data": [
        {
            "id": "1",
            "dg_name": "диуретики"
        },
        {
            "id": "2",
            "drug_name": "бета-блокаторы"
        },
    ]
}
```

### Пример выходных данных для одной группы ЛС
```json
{
    "result": {
        "status": 200, 
        "message": "Группа ЛС получена"
    },
    "data": {
        "id": "1",
        "drug_name": "диуретики"
    }
}
```

# API Для добавления группы ЛС
## Назначение
Добавление группы ЛС
## URL
```POST api/v1/addDrugGroup```
## Аутентификация
Требуемый статус: `admin`

## Вход
На входе в теле запроса получает название группы ЛС<br/>

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|dg_name|String|да|Название группы ЛС|

### Пример входных данных
Для добавления группы ЛС ```POST api/v1/addDrugGroup/``` <br/>
Тело запроса: <br/>
```json
{
    "dg_name": "диуретики"
}
```
 
## Выход
На выход отправляет статус выполнения запроса и соответсвующее сообщение<br/>

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|id|String|да|id группы ЛС|
|dg_name|String|да|Название группы ЛС|

### Статусы ответа
200 - Группа ЛС [название] добавлена<br/>
400 - Группа [название] уже существует<br/>
500 - Неизвестная ошибка сервера <br/>

### Пример выходных данных для успешного добавления группы ЛС
```json
{
    "result": {
        "status": 200, 
        "message": "Группа ЛС диуретики добавлена"
    },
    "data": {
        "dg_name": "диуретики",
        "id": 1
    }
}
```

### Пример выходных данных при ошибке
```json
{
    "result": {
        "status": 400, 
        "message": "Группа ЛС диуретики уже существует"
    },
    "data": {}
}
```

# API для удаления групп ЛС
## Назначение
Удаление групп ЛС
## URL
```DELETE api/v1/deleteDrugGroup/?dg_id=[id]```
## Аутентификация
Требуемый статус: `admin`

## Вход
На вход в теле запроса получает id группы ЛС, если параметр не отправляется, то выдается ошибка 400<br/>

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|dg_id|String|нет|id группы ЛС|


### Пример входных данных
Для удаления группы ЛС ```DLETE api/v1/deleteDrugGroup/?dg_id=1``` <br/>
 
## Выход
На выход отправляет статус выполнения запроса и соответсвующее сообщение<br/>

### Статусы ответа
200 - [название] удалено<br/>
400 - Ошибка определения удаляемого объекта<br/>
500 - Неизвестная ошибка сервера <br/>

### Пример выходных данных при успешном добавлении ЛС
```json
{
    "result": {
        "status": 200, 
        "message": "Группа диуретики удалена"
    },
    "data": {}
}
```

### Пример выходных данных при ошибке
```json
{
    "result": {
        "status": 400, 
        "message": "Ошибка определения удаляемого объекта"
    },
    "data": {}
}
```
