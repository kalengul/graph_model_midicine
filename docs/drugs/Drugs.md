# API Для получения ЛС
## Назначение
Получение одного или группы ЛС
## URL
```GET api/v1/getDrug/?drug_id={id}```
## Аутентификация
Не требуется

## Вход
На вход получает id получаемого ЛС. Если id не указан, то выводится список всех ЛС<br/>

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|drug_id|integer|нет|id ЛС|

### Пример входных данных
Для получение одного ЛС ```GET api/v1/getDrug/?drug_id=1``` <br/>
Для получение списка ЛС ```GET api/v1/getDrug/```

## Выход
На выход выдает список ЛС или информацию о конкретном ЛС<br/>

Выходные данные для одного ЛС<br/>

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:-------|:--------|:------|
|id|string|да|id ЛС|
|drug_name|string|да|Название ЛС|
|dg_id|Array(object)|да|Группа ЛС|
|nosology_id|int|да|Нозология ЛС|
|trade_ids|Array(object)|нет|Торговые наименования ЛС|

Выходные данные для списка ЛС<br/>

|**Праметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----|:--------|:--------|:------|
|drugs|Array(object)|да|Список объектов ЛС|

### Статусы ответа
200 - ЛС найдено / Список ЛС получен <br/>
404 - Лекарственное средство не найдено <br/>
500 - Неизвестная ошибка сервера <br/>

### Пример выходных данных для группы ЛС
```json
{
    "result": {
        "status": 200, 
        "message": "Список ЛС получен"
    },
    "data": [
        {
            "id": 61,

        {
            "id":	176,

            "dg_id": [139],
            "nosology_id":	1,
            "trade_ids": [1246, 1247, 1248, 1249, 1250, 1251]
```

### Пример выходных данных для одного ЛС

# API Для добавления ЛС
## Назначение
Добавление ЛС
## URL
```POST api/v1/addDrug```
## Аутентификация
Требуемый статус: `admin`

## Вход
На вход в теле запроса получает название ЛС и опционально список коэффициэнтов риска появления побочных эффектов<br/>

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|drug_name|String|да|название ЛС|
|dg_id|String|нет|Id группы ЛС|
|side_effects|Array(Object)|нет|Список побочек|

#### Объект side_effects
|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|se_id|String|да|id побочного эффекта|
|rank|Integer|да|ранг появления побочки|

### Пример входных данных
Для добавления нового ЛС ```POST api/v1/addDrug/``` <br/>
Тело запроса: <br/>
```json
{
    "drug_name": "амиодарон",
    "side_effects": [
        {
            "se_id": 1,
            "rank": 0.8
        }
    ]
}
```
 
## Выход
На выход отправляет статус выполнения запроса и соответсвующее сообщение<br/>

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|id|String|да|id ЛС|
|drug_name|String|да|Название ЛС|


### Статусы ответа
200 - ЛС [название] добавлено<br/>
400 - ЛС [название] уже существует<br/>
500 - Неизвестная ошибка сервера <br/>

### Пример выходных данных при успешном добавлении ЛС
```json
{
    "result": {
        "status": 200, 
        "message": "ЛС амиодарон добавлен"
    },
    "data": {
        "drug_name": "амиодарон",
        "id": 1
    }
}
```

### Пример выходных данных при ошибке
```json
{
    "result": {
        "status": 400, 
        "message": "ЛС амиодарон уже существует"
    },
    "data": {}
}
```

# API для удаления ЛС
## Назначение
Удаление ЛС
## URL
```DELETE api/v1/deleteDrug/?drug_id=[id]```
## Аутентификация
Требуемый статус: `admin`
## Вход
На вход в теле запроса получает id побочки параметр не отправляется, то выдается ошибка 400<br/>

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|drug_id|String|нет|id ЛС|

### Пример входных данных
```DELETE api/v1/deleteDrug/?drug_id=1``` <br/>
 
## Выход
На выход отправляет статус выполнения запроса и соответсвующее сообщение<br/>

### Статусы ответа
200 - [название] удалено<br/>
400 - Ошибка определения удаляемого объекта<br/>
500 - Неизвестная ошибка сервера <br/>

### Пример выходных данных при успешном добавлении ЛС
```json
{
    "result": {
        "status": 200, 
        "message": "Лекарственное средство амиодарон удалено"
    },
    "data": {}
}
```

### Пример выходных данных при ошибке
```json
{
    "result": {
        "status": 400, 
        "message": "Ошибка определения удаляемого объекта"
    },
    "data": {}
}
```
