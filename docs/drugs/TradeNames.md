# API Для получения торговых названий ЛС
## Назначение
Получение всех торговых названий для конкретного лекарственного средства по его ID
## URL
```GET api/v1/getTradeName/?drug_id={id}```
## Аутентификация
Не требуется

## Вход
На вход получает id ЛС, для которого нужно получить торговые названия<br/>

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|drug_id|integer|да|id ЛС|

### Пример входных данных
```GET api/v1/getTradeName/?drug_id=1```

## Выход
На выход выдает список торговых названий для указанного ЛС<br/>

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:-------|:--------|:------|
|drug_id|integer|да|id ЛС|
|drug_name|string|да|Название ЛС (МНН)|
|trade_names|array(object)|да|Список торговых названий|

Каждый объект в массиве `trade_names` содержит:

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:-------|:--------|:------|
|id|integer|да|id торгового названия|
|name|string|да|Торговое название|

### Статусы ответа
200 - Торговые названия получены <br/>
400 - Не указан параметр drug_id <br/>
404 - Лекарственное средство не найдено <br/>
500 - Неизвестная ошибка сервера <br/>

### Пример выходных данных
```json
{
    "result": {
        "status": 200, 
        "message": "Торговые названия получены"
    },
    "data": {
        "drug_id": 1,
        "drug_name": "амоксициллин",
        "trade_names": [
            {
                "id": 101,
                "name": "Амоксиклав"
            },
            {
                "id": 102,
                "name": "Флемоксин"
            },
            {
                "id": 103,
                "name": "Хиконцил"
            }
        ]
    }
}
```

# API Для загрузки торговых названий
## Назначение
Загрузка и обновление связей между МНН и торговыми названиями из JSON файла
## URL
```POST api/v1/trade_name_load/```
## Аутентификация
Требуется (администратор)

## Вход
На вход принимает JSON файл с маппингом МНН на список торговых названий<br/>

|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|file|file|да|JSON файл с данными о торговых названиях|

### Формат файла
```json
{
    "МНН_1": [
        "торговое_название_1",
        "торговое_название_2",
        ...
    ],
    "МНН_2": [
        "торговое_название_1",
        "торговое_название_2",
        ...
    ]
}
```

### Пример входных данных
```json
{
    "транексамовая кислота": [
        "битранекс®",
        "стагемин",
        "теовексал",
        "транавекс",
        "транексам®"
    ],
    "эптифибатид": [
        "апрокардикс",
        "интегрилин"
    ],
    "абиратерон": [
        "абират®",
        "абиратерон",
        "абиратерон канон"
    ]
}
```

## Выход
|**Параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:-------|:--------|:------|
|total|integer|да|Общее количество обработанных МНН|
|created|integer|да|Количество созданных торговых названий|
|updated|integer|да|Количество обновленных связей|
|errors|array(object)|да|Список ошибок при обработке|

## Статусы ответа
- 200 - Файл успешно обработан
- 400 - Файл не предоставлен или неверный формат
- 500 - Неизвестная ошибка сервера

## Пример выходных данных
```json
{
    "result": {
        "status": 200,
        "message": "Торговые названия успешно загружены"
    },
    "data": {
        "total": 3,
        "created": 15,
        "updated": 0,
        "errors": [
            {
                "drug_name": "неизвестное мнн",
                "error": "Лекарственное средство не найдено"
            }
        ]
    }
}
```
