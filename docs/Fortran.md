# API Для расчета взаимодействия по Fortran
## Назначение
Расчет совместимости ЛС по Fortran
## URL
```POST api/v1/polifarmakoterapiya-fortran/```
## Аутентификация
Не требуется
## Вход
|**параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|drugs|Array(integer)|да|массив id ЛС|
|humanData|Object|нет|Данные о пациенте (возраст, пол, противопоказания)|

Объект humanData

|**параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|age|integer|нет|Возраст пациента (лет)|
|gender|string|нет|Пол пациента: "man" или "woman"|
|cont_list|Array(string)|нет|Список ID противопоказаний (из справочника)|

### Пример входных данных
```json
"POST api/v1/polifarmakoterapiya-fortran/"
"data": {
    "drugs": [3, 11],
    "humanData": {
        "age": 25,
        "gender": "man",
        "cont_list": ["118", "41"]
    }
}
```

## Выход
|**параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|side_effects|Array(Object)да|Список побочных эффектов с рангами|
|SEFromDrug|Array(Object)да|Список побочных эффектов для каждого ЛС отдельно|
|drugs|Array(String)|да|Список названий проверяемых ЛС|
|сompatibility_fortran|String|да|Статус результата оценки совместимости по фортран|
|bannedPairs|Array(Object)|нет|Введённая комбинация содержит запрещённые пары ЛС|
|bannedPairsCont|Array(Object)|нет|Введённая комбинация содержит ЛС, которое запрещено при введённых данных пациента|
|rank_iteractions|Integer|да|Ранг совместимости по Fortran|
|combinations|Array(Object)|да|Применимость комбинации с другими лекарственными средствами|


#### Объект side_effects
|**параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|сompatibility|String|да|Статус результата оценки совместимости по фортран|
|effects|Array(Object)|да|Список побочных эффектов с рангами с данным статусом совместимости|

#### Объект effects
|**параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|se_name|String|да|Название побочного эффекта|
|rank|Integer|да|Ранг побочного эффекта|

#### Объект bannedPairs
|**параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|pair|Array(String)|да|Пара запрещённых препаратов|
|comment|String|нет|Описание запрещённой пары|

#### Объект combinations
|**параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|сompatibility|String|да|Статус результата оценки совместимости по фортран|
|drugs|Array(Object)|да|Список названий ЛС при добавлении которых будет сопоставимый статус совместимости|

#### Объект drugs в combinations
|**параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|name|String|да|Название ЛС|
|side_effects|Array(Object)|да|Список побочных эффектов с возможным рангом|

#### Объект side_effects в drugs
|**параметр**|**Тип данных**|**Обязательность**|**Описание**|
|:-----:|:--------|:--------|:------|
|se_name|String|да|Название ЛС|
|rank|Integer|да|Ранг побочного эффекта|

Допустимые статусы оценки комбинации: <br/>
`compatible` - Совместимы; <br/>
`incompatible` - Несовместимы;  <br/>
`caution` - С осторожностью; <br/>
`banned` - В введённой комбинации есть запрещённая пара; <br/>
`banned-contraindications` - ЛС несовместимо с противопоказанием пациента. <br/>

### Статусы ответа
200 - Совместимость ЛС по Fortran успешно расcчитана<br/>
400 - Отсутствует обязательное поле drugs;
    - Поле drugs передано в виде строки, но содержит невалидный JSON;.
    - Поле humanData передано в виде строки, но содержит невалидный JSON;
    - В системе нет ни одной записи о побочных эффектах;
    - Нарушена целостность данных в таблице DrugSideEffect (количество записей не равно Drugs × SideEffects);
<br/>
404 - Ресурс не найден<br/>
500 - Ошибка определения совместимости<br/>
